This project was for a robotics class I took in 2024.
If you put a whiteboard marker in the robot's claw and put it next to a whiteboard, the arm's movements will draw on the whiteboard.
This program plays hangman using the console and the robot.
Place the robot so that the upper arm faces the right, with a marker touching the board.
The robot is very sensitive to initial conditions, make sure the arm sections are as straight and perpendicular as possible before starting.
Movement is implemented using inverse kinematics. I used vector valued functions to allow the arm to move along a line or along an elliptical arc.
